# -Cplusplus-Program

# Summarize the project and what problem it was solving.

For this project we were tasked with creating an item tracking program that will analyze the text records generated throughout the day for a store called the Corner Grocer. They intended to use this program to get a better understanding of the items purchased in their store daily so that they can rearrange their inventory accordingly.

# What did you do particularly well?

I think that the way I implemented my class into my do-while loop was done well. It made the main code easy to read and follow and reduced a lot of clutter.

# Where could you enhance your code? How would these improvements make your code more efficient, secure, and so on?

I think I could have included a section that would catch all caps or randomized capitalizations of letters in the user input. This section could simply accept these imperfections as long as it is spelled correctly and given the information requested. 

# Which pieces of the code did you find most challenging to write, and how did you overcome this? What tools or resources are you adding to your support network?

The most challenging piece of code for me to write was opening and reading the text file. I went back through the reading material provided on these topics but I also searched through forums and videos on YouTube to help troubleshoot this issue. I made sure to take note of the information I found and also added different solutions to a running google doc that I have been using throughout my school year. When I come across something that I had trouble with I usually add it to the doc along with solutions and the information I used. 

# What skills from this project will be particularly transferable to other projects or course work?

I think that learning how to read, write and output from a file will be very useful in other projects and course work. I am sure that this will not be the last time that I will need to perform this task so having a working knowledge of it will be beneficial in the future.

# How did you make this program maintainable, readable, and adaptable?

I made this program easy to maintain by providing notes on what each section does so if something needs to be tweaked you can locate the code you need to change easily. I made sure to space out my code as well so that it can be read easily as well. I think that the do while loop can easily be adapted to what is needed for future programmers. They can easily add on a different class or manipulate the one I have and add the necessary code to the main loop and receive the output desired.
